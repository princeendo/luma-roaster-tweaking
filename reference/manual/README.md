# CBR-120POT manual

The manufacturer's user manual for the roaster, plus cleaned-up versions made from it. The printed manual calls the machine a "Home Coffee Bean Roaster", model CBR-120POT. "Luma" is the seller's name.

| File | What it is | Original file name |
|---|---|---|
| [cbr-120pot-user-manual-original-scan.pdf](cbr-120pot-user-manual-original-scan.pdf) | The original 14-page scan. Authoritative when a transcription is in doubt. | `Luma Roaster User Manual.pdf` |
| [cbr-120pot-user-manual.md](cbr-120pot-user-manual.md) | Searchable transcription with original page numbers. Use this for lookups. | `Luma_Roaster_CBR-120POT_Manual_Enhanced.md` |
| [cbr-120pot-user-manual.pdf](cbr-120pot-user-manual.pdf) | Typeset PDF of the transcription. | `Luma_Roaster_CBR-120POT_Clean_Manual_Enhanced.pdf` |
| [cbr-120pot-quick-reference.md](cbr-120pot-quick-reference.md) | One-page summary of limits, steps, settings and error codes. | `Luma_Roaster_CBR-120POT_Quick_Reference.md` |
| [cbr-120pot-quick-reference.pdf](cbr-120pot-quick-reference.pdf) | Printable quick reference. | `Luma_Roaster_CBR-120POT_Quick_Reference_Enhanced.pdf` |
| [cbr-120pot-temperature-profile.pdf](cbr-120pot-temperature-profile.pdf) | The redrawn reference temperature chart. | `Luma_Roaster_Temperature_Profile_Enhanced.pdf` |
| [assets/](assets/) | Images cropped from the scan and the redrawn chart. | `Luma_Roaster_Manual_assets_Enhanced/` (names changed from `snake_case` to `kebab-case`) |

The transcription and quick reference had their image and cross-document links updated for the new names. Their text is otherwise unchanged.

The redrawn chart is traced by eye from a blurry scan. It is an illustration, not measured data. The redraw leaves out several roast-level labels that the scan shows; [roaster-profile.md](../roaster-profile.md) lists them.
